Getting ready for a wider audience: the app now tells you more, and can be driven from outside.

New

  • The menu bar icon shows the state. A slash means the lid won't start your Mac; a bolt badge means plugging in won't. All four states are distinct at a glance.
  • Changes from the menu bar are confirmed. The password prompt closes the popover before it can show you the result, so a notification does it instead. LidBoot asks for notification permission on your first change from the popover — never at launch — and declining is respected.
  • "Takes effect after you shut down." The setting is read at power-on, so nothing changes until your Mac has been shut down once. The app now says so until that's happened.
  • lidboot:// URLs for Shortcuts, Raycast and scripts: lidboot://lid/off, power/on, all/off, restore, open. Same password prompt, same checks as a click.
  • Spanish, German and French, alongside English and Portuguese.
  • On an Intel Mac, the "can't help this Mac" screen now gives you the two Terminal commands for Intel's own setting (AutoBoot), copyable, with the caveats. LidBoot still never writes on Intel.
  • A Source code link in About.

Fixed

  • The Intel explanation claimed a wrong guess "risks an unbootable machine". That's true of a different variable on Apple silicon, not of Intel's; the real reason is that LidBoot can't verify writes on hardware it doesn't have. The copy now says that.
